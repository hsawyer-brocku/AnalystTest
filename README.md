<h1>Library Systems Analyst Hands-on Interview Project</h1>
<p>This project is meant as a hands-on project for displaying a weather dashboard in Python. This uses OpenWeatherMap and AirVisual API to grab weather information for specific locations</p>
<h2>Prerequisites</h2>
<p>Python will already be installed on your test system. You should not need this installed. If you get any errors or encounter any issues with the Python package, please troubleshoot as best you can. If you have any questions, feel free to ask us.</p>
<h3>Basic Overview</h3>
<p>1. You will need to clone this repository or download it. It is up to your preference.</p>
<p>2. Then you will need to install the requirements/modules</p>
<p>3. You will also need to be able to pass the script the environment variables (API Keys)</p>
<p>We would like for you to display the weather for Toronto for the next 2 days.</p>
